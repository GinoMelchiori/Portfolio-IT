# Portfolio de desarrollador web · Gino Melchiori

Sitio personal con proyectos (con vistas previas), experiencia, habilidades, formación y contacto. Hecho con HTML, CSS y JavaScript puro, responsive y con modo claro/oscuro automático.

## Estructura

```
index.html   Contenido de la página
styles.css   Estilos
app.js       Script mínimo (año del pie de página)
.nojekyll    Evita el procesado de Jekyll en GitHub Pages
```

## Publicar con GitHub Pages

1. Creá un repositorio público en github.com/new.
2. Subí los archivos con **Add file → Upload files** y hacé commit.
3. **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**.
4. En 1–2 minutos queda online en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Si el repositorio se llama `TU-USUARIO.github.io`, el sitio queda directamente en `https://TU-USUARIO.github.io/`.

## Editar

Los textos están en `index.html` y los colores en las variables del comienzo de `styles.css`.
